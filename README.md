# IT NEWS — 毎朝7時のAI・ITニュース5選

This repository automatically collects and summarizes AI and IT news from RSS feeds and publishes a daily digest on GitHub Pages.

It is designed to surface relevant technology updates in a compact daily format for quick reading and review.

🌐 **公開サイト（GitHub Pages）：[IT NEWSを開く](https://gongonticktack.github.io/it_news/)**

**株式日報とは独立**したニュースサイトです。GitHub Actionsで毎朝06:17 JSTに実行を予約し、06:47 JSTに予備実行します。7時までの公開を目指して、RSSやGoogle Newsから新着記事を取得します。
